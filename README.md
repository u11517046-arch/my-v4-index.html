# 四位數幾A幾B遊戲｜版本四

## 專案介紹
使用 Google Apps Script 製作的四位數幾A幾B遊戲。

## 版本四功能
1. Google 帳號辨識
2. 每位玩家獨立試算表
3. 遊戲紀錄自動儲存
4. 未完成遊戲可以繼續
5. 除錯模式
6. 多局遊戲紀錄

## 使用技術
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
